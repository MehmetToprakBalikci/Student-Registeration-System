# 🎓 Student Registration System

A full-stack course registration platform developed as a group project for the **CSE3063 - Object-Oriented Software Design** course at Marmara University. The system simulates a real-world university registration workflow with features like schedule conflict detection, prerequisite enforcement, and messaging between students and faculty.

---

## 🚀 Key Features

- 🧾 Student and instructor account management
- 📅 Course registration with **schedule conflict** and **prerequisite** validation
- 📧 Messaging interface between students and instructors
- 🔐 Authentication and session management
- 📊 Role-based dashboard views for students and instructors

---

## 🛠 Technologies Used

- **Backend:** Java (Servlets), JSP
- **Frontend:** HTML, CSS
- **Database:** MySQL
- **Tools:** Apache Tomcat, Git

---

## 🧩 System Modules

- **Authentication Module** – User login and session control
- **Registration Module** – Course listing, enrollment, conflict detection
- **Messaging Module** – Inbox system between students and instructors
- **Database Layer** – Centralized schema for users, courses, and registrations

---

## 📦 Setup Instructions

1. Clone the repository:
git clone https://github.com/MehmetToprakBalikci/Student-Registeration-System.git
cd Student-Registeration-System


2. Import the project into an IDE (e.g., IntelliJ IDEA or Eclipse)

3. Configure and start your MySQL database:
- Use the provided `schema.sql` to create the database and tables

4. Deploy the app to a Tomcat server

5. Access the system via `http://localhost:8080/Student-Registeration-System`
